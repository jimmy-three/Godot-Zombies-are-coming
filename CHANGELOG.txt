# 更新日志 (Changelog)

本文档记录项目的所有重要变更。版本号遵循语义化版本规范。

## [v1.0.0] - 2026-08-17
### Added
- 新增敌人“僵尸机器”与“僵尸机器boss”

## [v0.11.0] - 2026-08-14
### Added
- 新增日语语言支持
- 创建游戏开始界面（主菜单）
### Fixed
- 修复“基因靶向弹”不显示爆炸范围特效的问题
- 修复“基因靶向弹”飞行时间不统一的逻辑错误

## [v0.10.0] - 2026-08-13
### Added
- 新增语言切换选项（设置界面）
- 添加完整英语翻译支持
- 商店界面新增个人属性面板（展示玩家当前状态）

## [v0.9.0] - 2026-08-12
### Added
- “道具”类别新增“基因靶向弹”（可购买与使用）
- “狙击瞄准”新增开关功能（切换激光瞄准器开关状态）
- 新增枪械升级体系：
  - “冲锋枪” → “三头冲锋枪”
  - “加特林” → “狂暴加特林”
  - “狙击瞄准” → “精准射击”
- 新增多种射击音效

## [v0.8.0] - 2026-08-11
### Added
- “道具”类别新增“炮塔”（可购买与放置使用）

## [v0.7.0] - 2026-08-10
### Added
- “道具”类别新增“绷带”、“夯大力饮料”（可购买与使用）
- “道具”类别新增“狙击瞄准”（可购买与应用）
- 创建游戏内提示系统（HUD 消息通知）
### Changed
- 增加射击音效

## [v0.6.0] - 2026-08-09
### Added
- 完整实现商店系统：
  - “子弹”类别 5 个商品（九毫米、七点六二毫米、12号霰弹、炮弹、自动购买子弹）
  - “枪械”类别 4 个商品（冲锋枪、加特林、霰弹枪、狙击枪）
- 实现商品购买与装备使用功能

## [v0.5.0] - 2026-08-08
### Added
- 商店新增商品预览框（展示选中物品详情）
- “增益”类别 5 个商品可购买（伤害提升、射速提升、击退增强、速度提升、生命提升）
### Changed
- 完善商店 UI 布局与交互逻辑

## [v0.4.0] - 2026-08-07
### Added
- 创建商店界面与设置界面（按 ESC 键呼出）
- 添加商品图标占位（功能未完全实现）
- 添加商品名称与介绍文本
- 添加“旋转灵敏度”设置选项

## [v0.3.0] - 2026-08-06
### Added
- 创建“金币”系统
- 击杀僵尸掉落金币
- UI 新增“金币”显示

## [v0.2.0] - 2026-08-05
### Added
- 新增僵尸种类：
  - 普通僵尸
  - 迅速僵尸（移动速度更快）
  - 血厚僵尸（生命值更高）
- 新增对应 Boss 种类（每 20 波生成一个 Boss）：
  - 普通僵尸 Boss
  - 迅速僵尸 Boss
  - 血厚僵尸 Boss

## [v0.1.0] - 2026-08-03 (项目创建日)
### Added
- 创建项目，完成基础场景搭建（.tscn）
- 实现玩家角色：
  - 基础移动功能
  - 射击功能
- 创建环境装饰物（草），实现范围内随机生成
- 创建 UI 界面：
  - 添加“难度”显示，每 5 秒自动提升 1 级
- 创建敌人生成系统：
  - 僵尸 AI：面朝玩家移动
  - 僵尸属性随难度动态提升
