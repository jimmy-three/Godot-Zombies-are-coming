## 🎮 操作方式

- `WASD` 移动角色
- `空格` / `鼠标左键` 射击
- `←` `→` 转向（也可在商店购买“面向鼠标”功能）
- `ESC` 打开/关闭商店与设置界面
- 长按 `Q` 选择道具，`E` 使用道具
- `1` ~ `5` 切换武器

---

## 🧟 核心机制

- 动态难度：随时间自动提升，僵尸越来越强
- 多种僵尸：普通 / 侦查兵 / 士兵
- Boss 系统：每 20 波出现一次
- 金币系统：击杀僵尸掉落金币，用于商店消费

## 🚀 如何运行

1. 安装 [Godot 4.x](https://godotengine.org/download)
2. 克隆本仓库：
   ```bash

   ```
